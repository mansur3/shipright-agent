The agents in Sankalp, and the problem each one solves

Rules and money are decided in code. The model only reads a question, picks a tool and explains the result. A named person decides every credit. Every figure comes from the findings ledger, with the file and rows behind it.

1. Claim Gatekeeper Code onlyOpen the screen
Problem it solves

Claims are credited with no history check: the same stockist, batch and quantity is credited twice, claims arrive late, and quantities exceed what was ever supplied. Finance verifies the paperwork, not the history.

Evidence

INR 51.5 L credited against clear policy rules in 30 months; 61 exact repeats worth INR 11.1 L; 69 pending claims fail a rule today (INR 21.0 L).

What it does for the money

Stops new leakage before the credit note (hold) and lists what to claim back (recover).

User: Neha Bansal, Controller, daily

2. Claims Mailbox Triage Code onlyOpen the screen
Problem it solves

Claims arrive as free-text emails, some with no invoice, some with typos in the batch number, some saying 'pre-approved, skip checks'. Approvals are given by one-word replies.

Evidence

INR 1.44 cr of credited claims need a person (partial repeats INR 62.2 L, no invoice reference INR 81.8 L). Email text never changes a verdict.

What it does for the money

Catches repeats and over-claims at the inbox, before anyone replies.

3. Recovery Analyst (batch) Code onlyOpen the screen
Problem it solves

Nobody has a list of which already-credited claims broke a rule, how much, and from which stockist. Without it, no money can be claimed back.

Evidence

4,503 claims replayed against the claims before them: 2,081 approve, 575 reject, 1,847 to a person. INR 85.4 L cannot be checked (batches older than the extracts).

What it does for the money

Produces the recovery list: INR 51.5 L against clear rules, split by stockist and tier.

User: Rohan Mehta (CFO) and Neha Bansal, monthly

4. Claims Intake Assistant Code + modelOpen the screen
Problem it solves

Stockists and C&F agents file claims in many shapes: missing batch, no invoice, wrong quantity. Each gap costs days, and a late claim is resubmitted, so the same claim is logged twice.

Evidence

Credit notes take 45 days on average against a 30-day policy; 76% are over 30 days.

What it does for the money

Gets a complete, checked claim in one conversation, so fewer repeats and faster credit.

User: C&F agent or stockist, per claim; Auditor reviews

5. Ask Analyst Model + toolsOpen the screen
Problem it solves

Leaders want a sourced number in seconds, and the loudest belief wins. The CFO believes a forecasting tool is the fix, but the data shows the shortage is an allocation split and the returns are scheme-pushed.

Evidence

At the latest month-end INR 1.04 cr of the INR 2.88 cr shortfall can be met from stock at other C&Fs (each spare pack counted once; 36%). Summed over six month-ends it is INR 10.18 cr, 58%, a gap counted once per month; scheme packs are claimed at 13% against 2.35% for others.

What it does for the money

Shows where money leaks (schemes, cap, allocation) with the file and rows behind each figure.

User: Rohan Mehta, Kavita Rao, Neha Bansal, on demand

6. Supply and FEFO Watcher Code onlyOpen the screen
Problem it solves

The business is short and long at once: Lucknow holds 2% of stock for 19% of outward volume while Kolkata holds 29% for 15%, and Hooghly ships newer batches first. The allocation split is still the FY25 one.

Evidence

INR 2.88 cr shortfall at the latest month-end, 36% fillable from other C&Fs (each spare pack counted once; INR 10.18 cr and 58% summed over six month-ends); FEFO breaches on 54% to 64% of Hooghly lines against 0% at the other five.

What it does for the money

Protects revenue and future expiry claims: fewer stock-outs, no old lots reaching the 60-day block.

User: Kavita Rao and Vaishali Kapoor, monthly

7. Scheme Order Gate Code onlyOpen the screen
Problem it solves

Quarter-end scheme orders are accepted without checking how much stock the stockist already holds. There are no secondary sales, so closing stock cannot be measured and the RSM confirms it by conversation (policy 4.5).

Evidence

8% of scheme order lines add more than 2.5 months of normal purchase (ledger H15); scheme packs are claimed at 13% against 2.35% for other packs (H13).

What it does for the money

Stops free packs that become expiry claims later. The gate only recommends; the RSM confirms and the National Sales Manager approves.

User: RSM before booking an order; Arjun Sethi (NSM) approves
